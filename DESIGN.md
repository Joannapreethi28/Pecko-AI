# Pecko presentation workspace

## Direction
A quiet listening studio: warm paper, deep evergreen ink, spacious conversation area, and precise component evidence. The evaluator operates a working demo and reads results. The waveform is the signature geometric motif; it is a voice identity, never fake telemetry.

## Tokens
- Canvas: #f5f6f2. Surface: #ffffff. Sidebar: #eef0e9.
- Primary ink: #20392f. Secondary ink: #657167. Accent: #226b50.
- Accent wash: #e4efe7. Border: #dce2d9. Warning ink: #856329.
- Display/body: self-hosted Manrope with sans-serif fallback. Measurement labels use monospace and tabular numerals.
- Spacing: 4, 8, 12, 16, 24, 32, 40, 48 px. Primary surface radius: 16 px. Controls: 8 px.
- Focus: 3 px evergreen outline with 3 px offset. Motion: 180 ms state changes; reduced-motion respected.

## Layout and behavior
Desktop persistent sidebar, compact header and generous content. Demo studio contains the conversation and a status rail, followed by actual recorded audio. Benchmarks use aligned tables and source-derived horizontal bars. Pipeline illustrates the commit gate and replays recorded synthetic events. Evidence library links exact files. On small screens the sidebar becomes a top navigation row and columns stack.

## Content rules
Separate live text routing, recorded audio, component benchmarks and synthetic replay. Describe model availability, errors and recovery inline. No simulated microphone, claimed live CPU meter, fabricated conversation, or auto-playing audio. Numbers retain provenance, sample size and limitations.

## Guidance
Applied Impeccable SKILL.md, craft-floor.md and operate.md from https://github.com/pbakaus/impeccable. Local launcher was unavailable, so repository context and references were read directly. No global plugin installation is implied.
